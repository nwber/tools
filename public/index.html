tools.nbergeron.dev

Small tools, served from a Cloudflare Worker (Effect 4) deployed with Alchemy. Static pages are served by Cloudflare's asset layer; the API runs in the Worker.

Tools

  • AWS EBS Pricing — compare EBS volume costs across types and regions with IOPS/throughput limits and provisioning costs
  • EC2 Burst Calculator — CPU-credit simulation for t3a/t4g/t8i against the cheapest same-processor non-burstable instance (credits, throttling, unlimited surcharges, break-even)
  • S3 Cost Calculator — storage classes, request pricing, retrieval, and lifecycle transitions from the AWS price list
  • Speed Test — latency/jitter and parallel download/upload throughput against this edge
  • AWS Region Latency — browser-to-AWS round-trip latency per region (median + jitter against the regional DynamoDB health endpoints)

API

  • /ip — client IP as plain text
  • /ip.json — client IP + Cloudflare geo as JSON
  • /api/health — health check
  • /api/ebs/pricing — the EBS pricing dataset used by the calculator (/data/ebs-pricing.json is the same file for direct use)
  • /api/ec2/burst-spec — the burstable spec + comparison dataset (/data/ec2-burst-spec.json is the same file for direct use)
  • /api/s3/pricing — the S3 price dataset (/data/s3-pricing.json is the same file for direct use)
  • /api/aws/regions — the AWS region list and probe metadata used by the latency test (/data/aws-regions.json is the same file for direct use)
  • /speedtest/ping, /speedtest/down?bytes=N, POST /speedtest/up — the speed test endpoints (bounded sizes, per-IP rate limited)
