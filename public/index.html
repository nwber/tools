tools.nbergeron.dev

Small tools, served from a Cloudflare Worker (Effect 4) deployed with Alchemy. Static pages are served by Cloudflare's asset layer; the API runs in the Worker.

Tools

  • AWS EBS Pricing — compare EBS volume costs across types and regions with IOPS/throughput limits and provisioning costs

API

  • /ip — client IP as plain text
  • /ip.json — client IP + Cloudflare geo as JSON
  • /api/health — health check
  • /api/ebs/pricing — the EBS pricing dataset used by the calculator (/data/ebs-pricing.json is the same file for direct use)
