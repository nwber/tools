Measures HTTPS round-trip time from this browser to each AWS region's public endpoint — the regional DynamoDB health URL, which answers unauthenticated GETs with a tiny text body. Lower is better; compare regions relative to each other.

Each probe is a cross-origin fetch(mode: "no-cors") timed with performance.now(); AWS sends no CORS headers, so the responses are opaque and only their timing is visible. The first probe per region is discarded as DNS/TCP/TLS warm-up — the rest share a warm connection. Results are HTTPS round-trip estimates (network RTT plus TLS/HTTP overhead), not ICMP ping. US & Canada and Europe are pre-selected because that is what typically gets used from here; select more groups to compare further regions.
